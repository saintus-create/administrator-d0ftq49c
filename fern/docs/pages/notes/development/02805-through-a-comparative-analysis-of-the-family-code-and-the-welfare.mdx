Through a comparative analysis of the Family Code and the Welfare and Institutions Code, I have synthesized a major statutory contradiction regarding firearm restrictions. Under the Elder Abuse Act (Welfare and Institutions Code Section 15657.03), a protective order issued solely for financial exploitation or isolation explicitly exempts the respondent from mandatory firearm relinquishment. However, if an elderly petitioner files for a restraining order against an adult child under the Domestic Violence Prevention Act for the exact same conduct�which qualifies as 'coercive control' or 'disturbing the peace' under Family Code Section 6320�the firearm prohibition is mandatory and absolute. This procedural mismatch means the identical behavior carries completely different constitutional penalties depending entirely on which statutory path is selected, raising serious concerns about consistency and fairness for the accused.
