This archive contains 5,334 imported notes. Each entry retains its original title,
creation and modification dates, and a normalized plain-text body. The original CSV
export remains separately archived in the `NXES` repository.

Notes are assigned to these lightweight categories using title and content keywords:

- [Development](./development)
- [Finance](./finance)
- [Health](./health)
- [Ideas](./ideas)
- [Journal](./journal)
- [Tasks](./tasks)
- [Travel](./travel)
- [Uncategorized](./uncategorized)

Use the site search to find individual notes across every category. Categorization is
heuristic; it does not modify the note content.
